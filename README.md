# もち出口

8番出口のように「同じ通路を繰り返し歩き、異変があれば引き返す」だけの2D異変発見ゲーム。`index.html` 一枚で完結。

公開URL: https://masa0980-sudo.github.io/mochi-exit/

## 遊び方

「夕焼けのもち屋」「朝の茶屋」「たそがれの縁日」のどれか1つの通りが（毎回ランダムで）何度も出てくる。いつもと違うところ（異変）があれば「◀ 引き返す」、
何も無ければ「進む ▶」。正解を重ねて出口8にたどり着けば脱出。間違えると出口0からやり直し。
異変は通りごとに30種類・合計90種類（明らかなものから、看板の1文字違いや時計の針のズレまで）。
一度脱出すると、その通りで見つけた異変の数が画面右上に「発見 n/30」で表示される。

## プレイ回数の記録

姉妹プロジェクト（mochi-jump など）と同じ Firestore（`rythm-game-mo`）をカウンター保存先に使い、`gameId:"mochi-exit"` で記録する。
